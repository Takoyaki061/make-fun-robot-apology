A two-line robot confession for make.fun's "The Robot Apology" bounty: one sentence owning a specific mistake (a grey wool sweater washed on warm), one naming the lesson and the changed behaviour. The best entry takes the $2 reward.

## Run it

```sh
python3 main.py
```

It writes the apology to `/output/entry.txt`.
